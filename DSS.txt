	DSS - Donat Scan Save (Донат Сохранить Сканировать). Программа будет просить ввести такие вещи для сохранения: киты, привилегия, валюта, кейсы, услуга.
Киты: Какой кит, какой ник, какой способ оплаты(через какой банк), за сколько купил, время покупки, уникальный ID покупки. Привилегия: какая привилегия, на сколько (30, 60, 90 дней, навсегда)
какой ник, какой способ оплаты(через какой банк), за сколько купил, время покупки, уникальный ID покупки. Валюта: Токены: сколько купил, какой ник, какой способ оплаты(через какой банк), 
за сколько купил, время покупки, уникальный ID покупки. Кейсы: какой купил,
 какой ник, какой способ оплаты(через какой банк), за сколько купил, время покупки, уникальный ID покупки. Услуга: разбан/размут: что купил, какой ник, какой способ оплаты(через какой банк), 
за сколько купил, время покупки, уникальный ID покупки.
	Программа сохраняет это все, проверяет на наличие неверно вписанных полей (например 1990 год или число больше 100000 рублей, меньше 0 или отрицательное число. Для удобства будет давать выбор через раскрытие
(пользователь нажимает стрелку вниз рядом с полем ввода и будут по очереди высвечиваться названия, например (привилегия (и выбор между привилегиями) на сколько дней(30, 60, 90, навсегда) какой банк (выбор)). Выборы полей будут 
везде, кроме: ID покупки, никнейм, время (например 12.12.2023/12:00). 
Так же уже при помощи сохраненного списка с ценами доната, и при вводе каких то вещей (например доната) и вводе на какое кол-во времени суума доната сама будет рассчитываться уже из готовых цен. При нажатии 
на кнопку рядом с полем сумма можно редактировать ее (но, число не может быть больше 100000 рублей, меньше 10 или отрицательное число).
	У всех введенный пользователем полей, которые не дают право выбора, программа должна их проверять. Никнейм - не меньше 3 и не больше 30 символов, разрешен только английский и цифры. ID покупки может быть не меньше 
0 и не больше 1000000, ID не может повторятся с другими созраненными данными в базе данных (если есть покупка с ID 1, то в остальных покупках ID 1 ввести нельзя). Дата должна быть строго введена 
пользователем (день.месяц.год/время(между днем месяцем и годом должна стоять точка, после года нужно поставить слэш и написать время через :)) дата не может быть невозможной, например: 30.30.3033/49:88
 (число введеных символов должно быть ровно 16).
	При введении неправильно значения или оставленного пустово поля (не выбранно/не указанно) снизу должа в отдельное поле выводится все ошибки, которые были допущенны. Если значение введено верно, то оно подсвечивается 
зеленым глоу, неверно - красным. Должно четко выводится причина, например не указанно что то или такой ID уже существует.
	Будет сверху посиредине надпись DSS подсвеченная переливающимся глоу. Будет 3 кнопки. Сохранить Прочитать Изменить. для каждого есть отдельное окно. у сохранить и изменить будут одинаковый интерфейс, только вверху вместо
Сохранить будет изменить (если это окно изменения). Так же будет в окне изменить поле  куда нужно ввести ID для изменения и после ввода нужно будет нажать изменить (нужно учитывать что при изменении если не изменился 
ID то ругаться на это не нужно). В прочитать будет поиск (по дате/времени (четкая, от такого то времени или до такого то времени), нику, банку, стоимости(больше стольки то рублей,меньше стольки то рублей и виде услуг, ID)
 и сортировка(по стоимости, новые, старые). Данные будут либо выводится, либо будет сообщение ничего не найденно.
